# Staff-Management-System

## Project Overview
This is a web-based staff management system.

The purpose of this project is to provide a secure, modular, and scalable web-based staff management system to support staff with administration tasks.

## Tech Stack
1. Primary Language: C#
2. Frontend: HTML, CSS, JavaScript
3. Backend/Framework: ASP.NET Core MVC
5. Database: In-memory storage

## Features
1. Enforce administrator-only access
2. Support full staff CRUD functionality
3. Follow a layered architecture (Models, Services, Controllers, Views)
4. Use in-memory storage (future database-ready)
5. Be built and executed using modern .NET tooling
